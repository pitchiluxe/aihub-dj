# AIHub DJ 1.1.0

- Adds optional Ember Vinyl, Silver Wave, Silver Classic and Battle Artwork skins.
- Fixes palette selection across skins and keeps artwork across the full record.
- Refines console spacing, time displays and video-panel placement.
- Adds update notices, download progress, retry controls, and restart-to-update.
- Adds a manual update check in Settings and Windows notifications when the app is in the background.
- Updates the landing page's release download handling and update instructions.

## Install

Download AIHub-DJ-Setup.exe and run it on Windows 10/11 x64. Existing 1.0.0 users should install this version once; subsequent versions can be downloaded from the app's update notification.

## Future updates

The installed app checks for new public releases after launch and every six hours while open. Choose Download, then Restart to update when your set is finished. Downloaded updates can also install when the app closes.

The installer, blockmap and latest.yml belong to this same release. SHA256SUMS.txt contains the installer checksum.
