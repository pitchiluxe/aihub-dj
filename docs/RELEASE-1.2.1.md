# AIHub DJ 1.2.1

## Skins
- Every turntable skin now has real turntable details: a 45 adapter, a stylus target light that lights up when a record is loaded, an arm board, a playing lamp and a green pitch LCD.
- On the vinyl rigs (Classic 1200, Battle Artwork, Battle Black and Ember Vinyl), square CUE / stop / play / lock / SYNC keys run along the bottom of the deck.
- The rig skins use Classic text sizes for track titles, clocks, readouts and the browser.
- Cover-flow thumbnails appear in every skin again.

## Sampler sounds
- Every pad sound has been rebuilt to sound like the real thing: a dancehall air horn, a police wail siren, a "pew-pew" laser, a riser that builds from the first beat, a cinematic impact, a hand clap with room, a spin-back rewind and a tom fill.
- Fixes pads that were silent: CLAP was too quiet, and HIT and TOM were inaudible on laptop speakers. The horn no longer clips.

## Install

Download AIHub-DJ-Setup.exe and run it on Windows 10/11 x64. If you have 1.1.0 or later, the app's update notification offers this version.
