# AIHub DJ 1.2.0

- Rebuilds the reference skins as hardware replicas with large platters:
  - **Technics Silver** and **Technics Silver 4** have machined silver jogs with a live blue hub LCD that shows elapsed time and BPM. Technics Silver also has an amber mixer display.
  - **Classic 1200** has an aluminium plinth, black vinyl, green and red labels and an S-shaped tonearm.
  - **Battle Artwork** and the new **Battle Black** are black battle decks with a red power cap and a red LED mixer display.
  - **Ember Vinyl** has orange vinyl on a black plinth and a blue mixer LCD.
- In these skins, the transport sits in a column with a START·STOP key, and the track strips sit under the decks.
- Colour palettes repaint the rig skins. Choose "Skin original" to restore each rig's own finish.
- Fixes the red "AI DJ" tab, which wrapped onto two lines in the side panel.
- Track artwork still covers the full record, and the other skins are unchanged.

## Install

Download AIHub-DJ-Setup.exe and run it on Windows 10/11 x64. If you have 1.1.0, the app's update notification offers this version.
