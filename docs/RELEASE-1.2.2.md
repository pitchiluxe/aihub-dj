# AIHub DJ 1.2.2

- **Opens in a normal window:** AIHub DJ no longer opens maximized. It opens at the size and position you last left it. On first launch the window is centred and sized to fit your screen.
- **Original music only:** the AI DJ plays only original recordings by the real artists. It skips AI covers, AI-generated songs, and uploads from Suno, Udio or channels that label themselves AI music.
- **No volume jump on first play:** streamed songs no longer get louder by themselves about 24 seconds in. Auto-gain now levels a deck only while it can't be heard.
- **Technics tonearm:** every turntable skin has a Technics-style arm that rests beside the record, off the platter, until a song is loaded.
- **Deck colours:** the stylus target light glows red on deck B and blue on deck A.

## Install

Download AIHub-DJ-Setup.exe and run it on Windows 10/11 x64. If you have 1.1.0 or later, the app's update notification offers this version.
